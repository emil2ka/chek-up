# Чек-ап — мобильное приложение (Flutter)

Тот же «Чек-ап», что и [веб-версия](../web), на общем сервере и БД: чеки, профиль и список покупок видны на обоих устройствах.

## Запуск

```bash
flutter pub get
flutter run                                              # только на устройстве: данные локально, чеки — демо
flutter run --dart-define=API_URL=http://192.168.1.10:3000   # с сервером (его адрес в твоей сети или https://твой-сайт)
```

С `API_URL` включается синхронизация и настоящее распознавание чеков. Сервер — папка [`web`](../web) (`pnpm dev`).
Телефон и компьютер должны быть в одной Wi-Fi сети; для отладочных сборок iOS и Android разрешён обычный `http`.

**Подпись iOS.** Team ID не лежит в репозитории: впиши его в `ios/Flutter/Local.xcconfig` (файл в `.gitignore`):
`DEVELOPMENT_TEAM = ТВОЙ_TEAM_ID`.

## Проверки

```bash
flutter analyze
flutter test                                                         # расчёты и вёрстка каждого экрана на 3 размерах телефона
flutter test test/sync_live_test.dart --dart-define=API_URL=http://localhost:3000   # два устройства через живой сервер
```

## Устройство

| Папка | Что внутри |
|---|---|
| `lib/core` | расчёт сахара и оценки (`engine.dart`, те же формулы, что в вебе), модели, хранилище и синхронизация (`store.dart`), клиент сервера (`api.dart`), штрихкоды (`off.dart`) |
| `lib/screens` | главная, скан, результат, неделя, продукты, профиль, штрихкод, список покупок |
| `lib/ui` | стиль «Гора сахара» (`kit.dart`) и куча кубиков с физикой (`pile.dart`, forge2d) |
